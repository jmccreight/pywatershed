# Run 3: pywatershed below snow, driven by GSFLOW outputs

pywatershed with `PRMSSnow` (and everything above it) replaced by GSFLOW
output, fed as input to the below-snow processes. Tests the working hypothesis
that GSFLOW↔pywatershed divergence is dominated by `PRMSSnow` reproducibility.
See `../CLAUDE.md` for the full experiment description.

- **Driving data:** snow and above-snow variables taken from run 1's GSFLOW
  output (`../01_gsflow/output/`); below-snow processes computed by pywatershed.
- **Pattern reference:** `autotest/test_prms_above_snow.py` (and the below-snow
  companion) for instantiating a partial model and comparing variables.
- **Controls/inputs:** as for run 2, plus GSFLOW-derived inputs above snow.
- **`output/`:** git-ignored; regenerated by running the model.
